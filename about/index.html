Независимая образовательная среда для тех, кто хочет изучить SQL системно, разобраться в логике запросов и научиться работать с данными. Зачем нужен отдельный сайт

Обучающая платформа и самостоятельный образовательный ресурс решают разные задачи. Stepik предоставляет структуру курсов, последовательность уроков, задания и возможности проверки знаний. Здесь же можно изучить отдельную тему, быстро найти нужную конструкцию SQL, посмотреть пример и сразу выполнить собственный SQL-запрос в песочнице.

Этот сайт объединяет материалы, которые удобно иметь под рукой независимо от прохождения курса. Он служит справочником, рабочей тетрадью и дополнительной средой для практики. При этом полноценные курсы остаются на Stepik: сайт не копирует их содержание и не пытается заменить учебную платформу.

Откуда берутся данные о курсах

Информация о курсах, включая названия, количество уроков, учащихся, отзывы и рейтинги, поступает из публичного сервиса Stepik Stats (StepStat). Это сторонний сервис статистики работающий с API Stepik.

Специальный скрипт собирает данные, проверяет их структуру и сохраняет снимок в репозитории проекта. При сборке сайта используется сохранённая копия, а не запрос к внешнему API. Благодаря этому доступность стороннего сервиса не влияет на публикацию страниц.

Последний доступный снимок данных датирован 2 ноября 2026. Число учащихся, отзывы и другие показатели отражают состояние источника на момент обновления, а не данные в реальном времени. Если информация для отдельного показателя отсутствует, он не подменяется предположительным значением. Подробнее о методике и источниках статистики.

Ограничения и важные оговорки

01 / SQL-ДИАЛЕКТЫ

SQLite и MySQL

Песочница использует SQLite, а курсы на Stepik в основном построены вокруг MySQL. Базовые конструкции похожи, но типы данных, функции и отдельные возможности различаются. Запросы для другой СУБД необходимо проверять и при необходимости адаптировать.

02 / ПРОВЕРКА ЗАДАНИЙ

Без автоматического оценивания

Песочница позволяет самостоятельно выполнять запросы и сравнивать результаты с эталонными решениями. Она не отправляет задания на сервер и не выставляет оценки.

03 / СТАТИСТИКА

Сохранённые снимки данных

Показатели курсов загружаются из сохранённого снимка. Между обновлениями возможны расхождения с текущими данными на Stepik.

04 / РЕЙТИНГИ

Не для каждого курса

Рейтинг курса показывается при наличии подтверждённых отзывов. Для программы «SQL с нуля до результата» отдельный рейтинг не выводится, поскольку подтверждённого количества отзывов для неё нет.

05 / НЕЗАВИСИМОСТЬ

Неофициальный ресурс Stepik

Сайт не является официальным продуктом Stepik и организационно не связан с платформой. Описание, доступность, стоимость и условия прохождения курсов определяются на стороне Stepik.

Как устроен сайт

Проект построен как статический сайт на Astro. Страницы формируются при сборке, а интерактивные элементы работают на стороне браузера с использованием Vue. Текстовый редактор SQL построен на CodeMirror, а выполнение запросов обеспечивает SQL.js.

Песочница запускает SQLite непосредственно в браузере. Учебная база находится в памяти вкладки, поэтому для работы с ней не нужны серверная база данных, установка MySQL или отдельная учётная запись. SQL-запросы не отправляются на сервер проекта.

Сайт размещён на Vercel. Сборка использует локально сохранённые данные о курсах и не зависит от доступности Stepik Stats в момент публикации.

Чего на сайте нет

Проект не использует пользовательские аккаунты, собственную платёжную систему или серверную базу данных. Здесь нет аналитики и рекламных трекеров. Сайт не продаёт курсы, не принимает оплату и не выполняет автоматическую проверку домашних заданий.

Песочница предназначена для самостоятельной работы: её временная база данных находится в браузере и не сохраняется на сервере. После перезагрузки страницы состояние песочницы сбрасывается.
