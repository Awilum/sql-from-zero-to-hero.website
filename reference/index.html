SELECT

#select

Выбирает столбцы и выражения из таблицы или подзапроса.

Синтаксис

SELECT столбцы
FROM таблица
WHERE условие
ORDER BY столбец
LIMIT количество;

Пример

SELECT name, city
FROM customers
WHERE city = 'Москва'
ORDER BY name;
  • Перечисляйте столбцы явно вместо * в рабочем коде.
  • Порядок выполнения отличается от порядка написания: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.

WHERE

#where

Оставляет строки, для которых условие истинно.

Синтаксис

WHERE условие AND условие OR условие

Пример

SELECT name, price
FROM products
WHERE price BETWEEN 5000 AND 50000
  AND stock > 0;
  • AND имеет более высокий приоритет, чем OR; ставьте скобки.
  • NULL не сравнивается через = или <>. Используйте IS NULL и IS NOT NULL.

ORDER BY и LIMIT

#order-limit

Сортирует результат и ограничивает число строк.

Синтаксис

ORDER BY столбец ASC|DESC
LIMIT количество OFFSET пропустить;

Пример

SELECT name, price
FROM products
ORDER BY price DESC
LIMIT 5;
  • Без ORDER BY порядок строк не гарантирован.
  • LIMIT без сортировки не отвечает на вопрос «самые дорогие».

DISTINCT

#distinct

Удаляет повторяющиеся строки результата.

Синтаксис

SELECT DISTINCT столбец FROM таблица;

Пример

SELECT DISTINCT city
FROM customers
ORDER BY city;
  • DISTINCT применяется ко всей строке, а не к отдельному столбцу.
  • COUNT(DISTINCT column) считает уникальные непустые значения.

GROUP BY и HAVING

#group-having

Группирует строки и фильтрует готовые группы.

Синтаксис

SELECT столбец, COUNT(*)
FROM таблица
GROUP BY столбец
HAVING COUNT(*) > 1;

Пример

SELECT status, COUNT(*) AS orders_count
FROM orders
GROUP BY status
HAVING COUNT(*) >= 2
ORDER BY orders_count DESC;
  • WHERE фильтрует строки до группировки, HAVING — после.
  • Обычный столбец в SELECT должен входить в GROUP BY или быть агрегатом.

JOIN

#join

Соединяет строки нескольких таблиц по правилу ON.

Синтаксис

FROM левая AS l
JOIN правая AS r ON r.id = l.foreign_id

Пример

SELECT c.name, o.ordered_at, o.status
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.id
ORDER BY o.ordered_at DESC;
  • INNER JOIN оставляет только совпадения; LEFT JOIN сохраняет левую таблицу.
  • Проверяйте, не размножает ли соединение строки перед GROUP BY.
  • SQLite поддерживает RIGHT JOIN и FULL OUTER JOIN с версии 3.39.0+.
Хотите уверенно работать с JOIN? В курсах — подробные объяснения типов соединений, типичные ошибки и практика на реальных таблицах: изучать JOIN в курсах →

NULL

#null

Отмечает отсутствующее или неизвестное значение.

Синтаксис

WHERE столбец IS NULL
WHERE столбец IS NOT NULL

Пример

SELECT name
FROM customers
WHERE city IS NULL;
  • NULL — не ноль и не пустая строка.
  • Сравнение с NULL даёт UNKNOWN, а не TRUE.
  • COUNT(column) и AVG(column) обычно пропускают NULL.

CASE

#case

Возвращает значение в зависимости от условий.

Синтаксис

CASE
  WHEN условие THEN значение
  ELSE значение
END

Пример

SELECT
  name,
  CASE
    WHEN price >= 50000 THEN 'дорогой'
    WHEN price >= 10000 THEN 'средний'
    ELSE 'доступный'
  END AS segment
FROM products;
  • CASE можно использовать в SELECT, ORDER BY, GROUP BY и агрегатах.
  • ELSE не обязателен, но без него получается NULL.

Подзапросы и CTE

#cte

Разбивает запрос на промежуточные шаги.

Синтаксис

WITH имя AS (
  SELECT ...
)
SELECT ... FROM имя;

Пример

WITH paid AS (
  SELECT customer_id, id
  FROM orders
  WHERE status = 'paid'
)
SELECT c.name, COUNT(*) AS paid_orders
FROM customers AS c
JOIN paid ON paid.customer_id = c.id
GROUP BY c.id, c.name;
  • Скалярный подзапрос должен вернуть одно значение.
  • EXISTS удобен для вопроса «есть ли совпадение».
  • CTE улучшает читаемость, но не гарантирует ускорение.

Оконные функции

#window

Считают по набору строк, не сворачивая результат.

Синтаксис

функция(...) OVER (
  PARTITION BY столбец
  ORDER BY столбец
)

Пример

SELECT
  name,
  category_id,
  price,
  RANK() OVER (
    PARTITION BY category_id
    ORDER BY price DESC
  ) AS price_rank
FROM products;
  • Оконные функции нельзя использовать в WHERE; оберните запрос в CTE.
  • ROW_NUMBER не повторяет номера, RANK пропускает их при равенстве, DENSE_RANK — нет.
  • ORDER BY внутри OVER управляет вычислением, а не порядком вывода.

INSERT, UPDATE, DELETE

#dml

Добавляет, изменяет и удаляет строки.

Синтаксис

INSERT INTO таблица (столбцы) VALUES (...);
UPDATE таблица SET столбец = значение WHERE условие;
DELETE FROM таблица WHERE условие;

Пример

UPDATE products
SET stock = stock - 1
WHERE id = 1
  AND stock > 0;
  • UPDATE и DELETE без WHERE затрагивают все строки.
  • Перед изменением проверьте условие через SELECT.
  • Для нескольких операций используйте транзакцию.

Диалекты SQL

#dialects

Базовый синтаксис общий, детали различаются.

Синтаксис

-- SQLite / PostgreSQL
LIMIT 10

-- SQL Server
SELECT TOP 10 ...

Пример

-- MySQL: дата в формате YYYY-MM
SELECT DATE_FORMAT(ordered_at, '%Y-%m') FROM orders;

-- SQLite: тот же смысл
SELECT strftime('%Y-%m', ordered_at) FROM orders;
  • Функции дат, строк и преобразования типов сильнее всего различаются.
  • Проверяйте поддержку оконных функций и CTE в версии своей СУБД.
  • Песочница сайта — SQLite; курсы на Stepik в основном MySQL.
