## О книгах

Автором обоих книг является Сергей Романенко, основатель проекта SQL с нуля до результата. Книги написаны как дополнение к одноименным курсовым учебным курсам на Stepik.

### «SQL Введение»

Бесплатный учебник для тех, кто впервые знакомится с SQL. Рассказывает о таблицах, типах данных, основных командах SELECT, WHERE, ORDER BY, JOIN, агрегатных функциях, группировке и решении практических задач. Книга доступна для чтения прямо на сайте и для бесплатного скачивания с GitHub.

**Важно:** курс на Stepik полностью бесплатен. Книга — это теоретическое сопровождение, которое можно читать без регистрации. Для практики, тестов и взаимодействия с другими студентами рекомендуется записаться на курс.

### «SQL Общие табличные выражения»

Книга из курса по общим табличным выражениям. Объясняет, как WITH помогает разбить сложные запросы на простые шаги, заменять вложенные SELECT и подготовить данные к оконным функциям. Доступна только учащимся курса.

### Путь обучения

Начните с бесплатной книги или курса «SQL Введение» на Stepik. После освоения основ продолжите обучение через полный пакет **SQL с нуля до результата**, включающий дополнительные тематические курсы, практические тренажёры и продвинутые материалы.
